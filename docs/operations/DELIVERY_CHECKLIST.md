# 客户交付检查清单

> 每条视频交付前，按此清单逐项确认。全部通过才可交付。

---

## 交付物清单

### 必须项（缺一不可）

- [ ] **最终成片** `final.mp4` — 客户确认的主比例版本
- [ ] **字幕文件** `subtitles.srt` — 外挂字幕（可选，但推荐提供）
- [ ] **封面图** `thumbnail.jpg` — 视频封面/缩略图
- [ ] **交付报告** `delivery_report.json` — 含质检证明和交付指纹

### 推荐项（多比例派生）

- [ ] **竖屏版** `final_9x16.mp4` — 抖音/快手/视频号
- [ ] **横屏版** `final_16x9.mp4` — B站/YouTube/官网
- [ ] **方形版** `final_1x1.mp4` — 小红书/朋友圈

---

## 质量检查

### 画面质量

- [ ] 分辨率正确（竖屏 1080×1920 / 横屏 1920×1080）
- [ ] 帧率 30fps
- [ ] 无黑边、无拉伸变形
- [ ] 人物脸部清晰，无变形/扭曲
- [ ] 产品外观与参考图一致（颜色、材质、比例）
- [ ] 场景光线自然，无过曝/欠曝
- [ ] 段间衔接自然，无跳变/断层

### 音频质量

- [ ] 音量适中，无爆音/破音
- [ ] 配音与口型同步（口播类必须逐段检查）
- [ ] 背景音乐不盖过人声
- [ ] 段间音色/音调/语速一致（多段视频）

### 文字质量

- [ ] 字幕无乱码、无错别字
- [ ] 字幕时间轴与语音精确同步
- [ ] 字幕位置不遮挡关键画面元素
- [ ] 动效文字与画面融合自然
- [ ] 品牌 Logo/标识清晰可读

### 内容质量

- [ ] 台词/旁白与确认版一致
- [ ] 产品信息与客户确认的一致
- [ ] 无 AI 味台词（"让我们一起"、"在当今社会"等）
- [ ] 无违反广告法的绝对化用语
- [ ] AI 生成内容已添加披露标识

### Agent / LLM 合同质量

- [ ] 宿主只通过 `workflow_api.py next` 取得当前阶段，没有复制业务流程
- [ ] 创意修改有当前 `question_id`、目标 SHA-256、允许路径和事实/客户证据
- [ ] manifest、审批、客户原话、任务 ID 和资产指纹没有由 LLM Patch 写入
- [ ] `workflow_router.py validate`、`skill_contract.py validate` 和 36 项评测夹具校验通过
- [ ] 未通过业务评测的模型保持 atomic 模式，没有扩大批量或绕过闸门
- [ ] `release_audit.py` 的当前源码指纹校验通过，报告中所有命令退出码为 0
- [ ] 离线运行时校验通过，目录清单与 ZIP 内部清单/SHA-256 均复验通过
- [ ] ZIP 不含路径穿越、重复成员、异常符号链接、未声明文件或密钥样式文本
