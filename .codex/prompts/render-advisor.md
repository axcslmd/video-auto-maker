# 渲染 & 融合方案顾问（LLM 现场推荐 + 引导客户选择）

风格表（`render-style-guide.md`）是**静态基线**。这份指南定义在它之上的一层：**大模型结合当前客户的产品、素材、目标，现场生成渲染方式和融合方式的推荐方案，给客户 2-3 个选项 + 明确推荐 + 理由，引导客户选，再把决策写回 brief。** 不要替客户默默定，也不要只丢一个方案。

## 什么时候触发

任何场景 skill 在「确认脚本」之后、「调模型出片」之前，插入这一步。

## 输入（先读，别凭空推荐）

```
python3 scripts/asset_prep.py brief --client <client>     # product_type, render_profile, specs, 已导入素材
python3 scripts/digital_human.py list --client <client>   # 有哪些数字人形象
python3 scripts/brand_kit.py get --client <client>        # 主色/logo/风格
```
看清楚：客户有没有实拍图/footage？有没有数字人形象？产品类型对应什么风格？目标是带货还是品牌？

## 你要现场生成的两类推荐

### A. 渲染方式（怎么把画面生成出来）

从下面能力里，按客户实际素材选出最合适的 2-3 个组合，**不是全列出来**：

| videoType | 渲染方式 | 适用 | 生成成本 |
|---|---|---|---|
| 1 文生视频 | 纯提示词生成画面/动态文字 | 无素材、纯创意、kinetic text | 中 |
| 2 图生视频（首帧） | 让一张产品实拍图动起来 | 有产品图、想真实感 | 中 |
| 3 图生首尾帧 | 指定起止画面做转场 | 要精确运镜/变身 | 高 |
| 4 图生参考图 | 锁定数字人/产品形象出镜 | 数字人口播、形象一致 | 高 |
| 5 多图参考 | 多素材融合（人+产品+场景） | 复杂同框、素材丰富 | 高 |

模型路由以运行时能力表为准：默认优先 Seedance，不可用时尝试 Kling；正式含台词段只能选择网关明确支持音画一体的模型，不能把无声模型作为口播成功兜底。videoType 4 只有 Kling 支持；videoType 5 可由 Seedance/Kling 支持。无台词或纯音乐段才可继续回落 WAN。若 TVC/中文人物质感评估明确需要 Kling，可以在给客户说明质量、成本和时延取舍后显式选择。**不要推荐 veo3.1**。提质主要依靠正式 take 重试/择优、1080p、真实锚图和负向约束。

### B. 融合方式（多个片段/元素怎么组合成成片）

| 融合方式 | 说明 | 适用场景 |
|---|---|---|
| 单镜到底 | 一段生成直接成片 | 5-10s 社交快剪 |
| 分段拼接（数字人+实景） | 各段独立生成 → `compose.py concat` | 服务介绍、产品演示 |
| 实拍 footage + 数字人混剪 | 客户真实拍摄 + 生成段拼接 | 有实拍素材、要真实感 |
| 动态文字融合 | 视频/图 + kinetic text 叠加 | 强调卖点数字、促销信息 |
| 数字人 + 产品图同框（多图参考） | videoType 5 融合 | 人货同框展示 |

融合方式决定后续是"一次生成"还是"分段生成再拼接"，直接影响生成成本和成片结构。

## 引导话术模板（照此语气）

```
你：根据你的产品（<品类>）和现有素材（<有/无实拍图、有/无数字人>），
    我给你两个出片方案，你选一个：

    方案A【推荐】<渲染方式+融合方式>
      - 怎么做：<具体，如"产品实拍图走图生视频 + 数字人讲解段，拼接成片">
      - 效果：<真实感强/高级感/出片快>
      - 适合：<你的目标人群/平台>
    方案B <另一种>
      - 怎么做：…
      - 取舍：<更快但真实感弱 / 更贵但质感高>

    我推荐 A，因为 <结合客户实际的理由>。你倾向哪个？也可以说你的想法我再调。
```

要点：
- 每个方案都要有**具体做法 + 效果 + 取舍**，不是抛术语。
- 明确给**推荐**并说**为什么**（结合这个客户的素材/预算/目标，不是泛泛而谈）。
- 主动点出风险：数字人口型保真、logo 在动态中可能变形、粤语 TTS 局限、实拍缺失只能纯生成等——诚实告知。
- 客户拿不准时帮他决定，但要让他确认。

## 决策写回 brief

客户选定后记录，供出片步骤和复盘引用：
```
python3 scripts/asset_prep.py set-render-plan --client <client> \
  --plan '{"render_method":"videoType2图生+videoType4数字人","fusion":"分段拼接","model":"kling-v3-omni-video","reason":"客户有产品实拍图+数字人形象,要真实感+形象一致","segments":["实景段","数字人讲解段"]}'
```

## 完成标准

- 给了客户 2-3 个结合其实际的渲染+融合方案，有推荐有理由。
- 客户明确选定；决策写回 brief 的 `render_plan`。
- 风险已如实告知。出片严格按选定方案执行。
