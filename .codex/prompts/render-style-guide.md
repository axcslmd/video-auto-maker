# 渲染风格判断指南（LLM 参考，非用户命令）

这份指南供当前本地 Agent 在写画面提示词/动效脚本前，**根据产品类型判断动画风格与渲染参数**。不要固定套一个模板——先判品类，再定风格。判断结果用 `asset_prep.py set-profile` 写回 brief，供各场景 skill 复用。

## 判断流程

1. 读 brief（`asset_prep.py brief`）——看 product_type、specs、texts 推断品类。
2. 若 product_type 为空，你根据产品资料**自行判断品类**（数码3C/美妆/食品饮料/母婴/服饰/家居/金融/教育/健康…）。
3. 按下表映射出 render_profile；拿不准时在引导对话里跟客户确认风格方向（给 2 个选项+推荐）。
4. 写回：`python3 scripts/asset_prep.py set-profile --client <c> --product-type "<品类>" --render-profile '<JSON>'`

## 品牌主色与配色规则

先确认品牌主色（hex），再判断行业风格。不要把“企业讲解/科技服务”默认套成深蓝或苹果蓝；主色来自客户品牌包、Logo、官网或客户确认。参照 Color-Palette-Skill 的配色思路：品牌色做锚点，行业/情绪/使用场景决定辅助色，背景和面板用低饱和柔和层次，文字用清晰中性色，强调色只保留 1–2 个。

写 `palette_hint` 时使用「品牌主色 + 柔和背景层次 + 辅助色」而不是固定色名；例如“品牌主色 #C5162E + 深酒红灰背景 + 柔和金色数据高光”。

## 产品类型 → 动画风格 / 渲染参考

| 产品类型 | 视觉风格 | 动效手法 | 色调/节奏 | 字体感 |
|---|---|---|---|---|
| 数码 3C / 电子 | 科技快闪、未来感 | 粒子汇聚、电流光效、快切、光扫 | 深色+品牌色，节奏快 | 无衬线粗体 |
| 美妆 / 护肤 | 优雅高级、柔光质感 | 缓入缓出、丝滑位移、光晕 | 柔和粉/裸色/金，节奏慢 | 细衬线优雅 |
| 食品 / 饮料 | 活力暖调、诱人 | 弹跳、Q弹缩放、飞溅动感 | 高饱和暖色，节奏中快 | 圆润粗体 |
| 母婴 / 儿童 | 温馨柔和、可爱 | 轻柔浮动、手绘感、软弹 | 低饱和马卡龙，节奏慢 | 圆体手写感 |
| 服饰 / 时尚 | 时尚大片、编辑感 | 硬切、大字排版、镜头推拉 | 高对比黑白/单色，节奏中 | 时装体细高 |
| 家居 / 生活 | 自然简约、温暖 | 缓慢平移、渐显 | 大地色/原木,节奏慢 | 人文衬线 |
| 金融 / 科技服务 | 专业稳重、信任感 | 数据线条、几何、稳态渐显 | 品牌主色驱动的低饱和商务层次,节奏稳 | 无衬线中性 |
| 教育 / 知识 | 清晰友好、明快 | 板书感、图标弹出、引导箭头 | 清爽蓝绿,节奏中 | 圆润易读 |
| 健康 / 医疗 | 干净可信、轻盈 | 柔性渐入、呼吸感 | 白+清新绿蓝,节奏慢 | 无衬线清晰 |

> 表是起点不是枷锁。结合 brief 的品牌调性（brand-kit 主色/风格）和目标人群微调；跨界产品（如"高端电竞美妆灯"）可融合两种风格。

## render_profile JSON 结构（写回 brief）

```json
{
  "visual": "科技快闪、未来感",
  "motion": "粒子汇聚、电流光效、快切",
  "palette_hint": "品牌主色 <确认主色hex> + 低饱和深色背景 + 柔和辅助高光",
  "pace": "快",
  "font_feel": "无衬线粗体",
  "video_style_prompt": "商業廣告動態，品牌主色作為視覺錨點，低飽和高級背景層次，柔和高光點綴，kinetic typography 高級質感"
}
```

`video_style_prompt` 是关键——它作为**风格前缀**拼进每次调视频/图像模型的提示词，保证同一产品所有产出风格统一。

## 用法（各场景 skill 出片前）

出片/出图前先取风格：
```
python3 scripts/asset_prep.py brief --client <client>   # 读 render_profile.video_style_prompt
```
把 `video_style_prompt` 拼在具体画面提示词前，再调 `video_engine.py` / `create_image`。
这样数码产品自动科技风、美妆自动优雅风，无需每次重定。

## 完成标准

- brief 里有 product_type 和 render_profile；video_style_prompt 可用。
- 各场景/动态文字出片都带上该风格前缀，风格与品类匹配、跨产出统一。
