# UGC 第一人称测评配方

先读取当前 run 的 router contract，再把本配方应用到相应阶段：

```bash
python3 scripts/workflow_router.py contract --manifest <manifest.json>
python3 scripts/skill_contract.py contract --skill ugc-review
```

## 脚本

- 全程第一人称，以真实感受开场，再讲 2–3 个具体使用细节，最后自然推荐。
- 使用口语停顿和适度犹豫，至少包含一个不完美或适应过程。
- 禁止无证据的“第一、唯一、永久、绝对”和空泛的“赋能、生态、闭环、颠覆”。
- CTA 保持软性，不把 UGC 写成品牌发布稿。
- 将目标总时长拆成符合实时视频模型能力的多个 shot；不要把 30–60 秒总片长写成一个 segment 的 `duration`。

## 人物与画面

- 人物定义写入稳定自拍身份特征：近中景、轻微高机位、自然服装、生活化环境和适度手持感。
- 自然选择卧室、车内、咖啡店或厨房等与产品相关的真实场景，不固定套模板背景。
- 故事板中自拍构图约占 40%，其余使用产品特写、手部接触和使用状态形成景别变化。
- 相邻镜头仍满足角度、景别或构图重心变化，避免连续同角度自拍。
- 产品与人物发生接触时必须走正式 `product_usage` 阶段。

## 生成与质检

- 每个 shot 的 `video_type` 由素材数量和实时模型能力决定，不在配方中固定为单一类型。
- 画面保持无字幕、无广告标签、无后加 Logo；文字元素交给后期。
- 检查脚本口语感、人物身份、产品可见性、手部关系、生活化光线和 OCR。
- 若客户只需要产品无人物展示，切换到 `product_showcase`；不要强加数字人 UGC。
